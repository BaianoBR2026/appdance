# AppDance

Jogo de dança e minijogos com a câmera do celular (MediaPipe Pose), para 1 a 3 jogadores.

- `tela.html` — **Telão** (projetor, TV ou PC): só mostra o jogo, o vídeo e toca os sons.
- `celular.html` — **Câmera** (celular): o cérebro. Filma até 3 pessoas, roda os jogos e conta os pontos.
- `solo.html` — Dança num aparelho só (PC ou celular).
- `poses.html` — Primeiro protótipo (treino de poses).
- `video.html` — Versão antiga do modo vídeo.

Jogos: Dança, Estoura Balões, Corrida Parada, Estátua, Desvia!

Site: https://appdance.netlify.app — publicado automaticamente pelo Netlify a cada atualização deste repositório.
